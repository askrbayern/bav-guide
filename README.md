# 二叶式主动脉瓣修复：三维术式对照与文献数据

[打开三维对照](https://askrbayern.github.io/bav-guide/) · [浏览文献与数据](https://askrbayern.github.io/bav-guide/data.html)

16 个解剖与术式分支，用于比较瓣叶、瓣环及主动脉根部的结构关系。网页支持旋转、缩放、双视角同步，以及开放期／关闭期切换。

## 内容

| 文件 | 内容 |
|---|---|
| `index.html` | 运行库内嵌的三维展示网页 |
| `data.html` | 可直接阅读的数据表与 CSV / JSON 下载入口 |
| `data/techniques.*` | 16 个展示分支及图形参数 |
| `data/evidence.*` | 10 条结构证据与适用边界 |
| `data/references.*` | 9 个原始文献入口及证据层级 |
| `data/cohorts.*` | 5 个研究队列、分母定义及重叠说明 |
| `data/observations.*` | 21 条术式组成与随访观察计数 |

资料快照为 **2026-09-12**；数据包整理日期为 **2026-10-13**。此次整理不代表新一轮系统检索或所有来源的重新医学核验。

## 使用

在线阅读直接打开上方网页。下载 `index.html` 后，可用支持 ES modules、import maps 与 WebGL 的现代浏览器打开；三维运行无需外部 CDN。论文入口需要联网。

完整网站由本目录的 HTML 与 `data/` 组成，GitHub Pages 从 `main` 分支根目录发布。移动端为单列展示；实际微信浏览器的 WebGL 支持与网络访问情况仍需在设备上验证。

字段、缺失值和使用范围见 [数据说明](data/README.md)。静态内容、数据关联及三维几何检查可运行 `node tools/check.mjs`。

## 读图与读表

- 展示分支不是相互独立的手术，也不构成医生排名。同一研究可涉及多个步骤。
- 模型的角度、尺寸、材料形变和缝线数量仅作示意；剖开图不代表实际手术切口。
- 原生瓣叶保留与根部窦壁保留是不同维度。David 保留瓣叶并替换窦壁。
- 中山与 UKE 的部分技术依据仍为摘要层级；Frankfurt 补片分支描述历史时期。
- 队列可能重叠；完成修复、意向修复与末次心超分母不能混用。此数据集不是患者级数据或完整文献库。
